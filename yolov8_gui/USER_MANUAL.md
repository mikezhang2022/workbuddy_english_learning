# YOLOv8 可视化工作台 — 操作手册

面向日常使用的中文说明。按步骤操作即可完成：导入数据 → 标注/增强 → 训练 → 对比模型。

---

## 1. 软件简介

本软件是一套基于 Tkinter 的桌面工具，把 YOLOv8 常见流程收进三个窗口：

| 工具 | 做什么 |
|------|--------|
| **图片/视频工具** | 导入媒体、自动标注、质检、数据增强、导出数据集 |
| **模型训练工具** | 选超参、GPU/CPU 训练、看损失与 mAP 曲线 |
| **模型对比工具** | 两个模型对同一图/视频预测，生成差异分析报告 |

三个工具共用一个**工作区**目录，路径、`data.yaml`、权重会自动记住，减少来回拷文件。

界面为**简体中文 + 浅色主题**（版本见启动器标题，当前为 **v1.0.2**）。

---

## 2. 环境要求与安装

### 环境要求

- Python **3.10** 及以上
- 建议安装 NVIDIA 驱动 + CUDA（有 GPU 会快很多；没有也能用 CPU）
- 磁盘空间：首次下载 `yolov8n.pt` 与依赖大约需要数百 MB

### 安装步骤

在仓库中进入 `yolov8_gui` 目录：

```bash
cd yolov8_gui
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

`requirements.txt` 会安装 ultralytics、torch、opencv、matplotlib、Pillow 等依赖。若本机已有匹配 CUDA 的 PyTorch，也可按官方说明单独安装 torch，再装其余包。

## 3. 启动方式

### 打开启动器

```bash
python main.py
```

启动后会看到工作区路径、三个工具卡片，以及环境/硬件检测信息。

### 直接打开某个工具

```bash
python main.py --tool image      # 图片/视频工具
python main.py --tool train      # 模型训练工具
python main.py --tool compare    # 模型对比工具
```

### 指定工作区

```bash
export YOLOV8_WORKSPACE=~/my_yolo_project
python main.py
```

也可在启动器里点「浏览」选目录，再点「应用」。

## 3.1 设置：调节字体大小与界面缩放

若觉得界面文字偏小，可在启动器中打开设置：

1. 点击主窗口右上角 **「⚙ 设置」**，或菜单栏 **工具 → 设置**
2. 在弹出的「设置」窗口中：
   - **界面字体大小**：拖动滑块（约 10–20），默认 **12**；拖动时设置窗口文字会立刻变大/变小，便于预览
   - **界面缩放 (DPI)**：约 **0.8–1.5**，步进 0.05，默认 **1.0**；可整体放大按钮、卡片间距与窗口尺寸
3. 点 **「保存并应用」**：写入配置并刷新主窗口
4. 点 **「恢复默认」** 可回到字体 12、缩放 1.0

配置保存在：

| 位置 | 文件 |
|------|------|
| 程序目录 | `yolov8_gui/yolov8_gui_config.json` |
| 当前工作区 | `config.json`（与程序目录同步写入） |

下次启动 `main.py` 会自动读取；若文件不存在则用默认值。

**说明**：保存后主窗口会立即按新字体/缩放重建。若此时已打开图片/训练/对比工具窗口，请先关闭再重新打开，才能完全套用新样式。

## 4. 工作区概念

工作区是一个文件夹，默认一般是用户主目录下的 `yolov8_workspace`。里面会放：

| 内容 | 说明 |
|------|------|
| `workspace_state.json` | 记住上次的 data.yaml、权重、对比模型路径 |
| `config.json` | 界面字体大小与 UI 缩放（与程序目录配置同步） |
| `imports/` | 导入的原始图片/视频 |
| `dataset/images`、`dataset/labels` | 标注后的图片与 YOLO 标签 |
| `export/` | 导出的 train/val 与 `data.yaml` |
| `runs/` | 训练输出（含 `best.pt`） |
| `frames/` | 从视频抽帧的临时图 |

**建议**：每个项目用单独工作区，避免数据集和权重互相覆盖。

## 5. 图片/视频工具使用说明

点击启动器里的「打开」，或 `python main.py --tool image`。

### 5.1 选择模型

- 顶部「模型 (.pt)」可「浏览」自己的权重。
- 「使用默认」会用 `yolov8n.pt`（COCO 预训练）。自动标注出来的是 COCO 类别；若要自己的类别，请先训练自定义模型，再回来标注。

### 5.2 导入

- **导入图片**：多选图片
- **导入视频**：单个视频
- **导入文件夹**：递归扫描图片和视频

左侧「媒体列表」可点选预览。

### 5.3 自动标注

点「自动标注」后，程序会：

1. 加载模型  
2. 对每张图写 YOLO `.txt` 标签到 `dataset/labels`  
3. 视频会按间隔抽帧再标注  

状态栏会显示进度。标注结束后若样本偏少，会提示去「数据增强」。

### 5.4 数据质检

右侧「数据质检」选项卡：

1. 点「运行质检」  
2. 查看模糊、过暗/过亮、近重复、缺标签、空标签、无效框、类别分布  
3. 需要时可点「一键优化」（去重、CLAHE、锐化、标签范围修正等）

### 5.5 数据增强

「数据增强」选项卡中勾选变换（水平翻转、旋转、亮度、CLAHE、锐化等），设置**倍数**。

- **预览增强效果**：看一张示意  
- **运行数据增强**：真正写出新样本  

下方会显示「预计新增样本」数量。

### 5.6 导出数据集

「导出」选项卡：

1. 可设「最少图片阈值」（默认 50，仅作提醒）  
2. 「导出 train/val + data.yaml」：约 80%/20% 划分，生成 `export/data.yaml`  
3. 「发送到模型训练工具 →」：自动打开训练窗口并带上该 yaml  

也可「导出标注视频」：先选中列表中的视频，再导出带框的 mp4。

## 6. 模型训练工具使用说明

`python main.py --tool train`，或从图片工具「发送到模型训练工具」。

### 6.1 选择数据集

顶部填或「浏览」`data.yaml`。若刚从工具 1 发过来，路径会自动填好。

样本不够、想回去增强时，点「发送到图片/视频工具 →」。

### 6.2 自动参数 / 手动参数

- **自动（推荐）**：按数据集规模给出轮数、学习率、批次大小等，并显示简要说明。  
- **手动**：自行改参数（轮数、学习率、批次大小、输入尺寸、优化器、动量等）。

### 6.3 训练建议与一键修复

「训练建议」列表会提示：

- 批次过大可能爆显存  
- CPU 训练时批次建议调小  
- 学习率过高/过低  
- 轮数过少  
- 没有验证集  
- 训练图太少、类别严重不平衡  

选中一条，点「应用所选修复」；若建议是去增强或补验证集，会跳到图片/视频工具。

### 6.4 GPU 加速

窗口底部显示当前设备。有 CUDA 时用 GPU（如 `0` + 显卡名）；没有则提示 CPU。启动器环境面板也会写明。

### 6.5 开始训练与曲线

1. 点「开始训练」  
2. 「训练日志」滚动输出  
3. 「实时指标」绘制训练损失、验证损失、mAP50  
4. 需要时点「停止」  

成功后状态会显示最佳权重路径，并写入工作区，方便对比工具直接用。

## 7. 模型对比工具使用说明

`python main.py --tool compare`。

### 7.1 选择两个模型

- **模型 A / 模型 B**：分别「浏览」`.pt`，或点「默认」用 `yolov8n.pt`  
- 若刚训练完，模型 A 有时会自动带上最近的 `best.pt`

### 7.2 选媒体并运行

1. 「选择图片」或「选择视频」  
2. 「运行对比」  

视频会采样若干帧（内部有上限），避免过慢。

### 7.3 看结果

- **并排预览 + 差异叠加**：左 A、中 B、右差异（仅 A / 仅 B）  
- **分析报告**：检测数、匹配数、IoU、耗时、漏检、置信度、类别分布  
- **置信度分布**：直方图  
- 下方「改进建议」给出选型/重训提示  

### 7.4 导出报告

- 导出 HTML 报告  
- 导出文本报告  
- 保存图表 PNG

## 8. 常见问题

### 样本不足怎么办？

- 在图片/视频工具里提高「数据增强」倍数并运行  
- 多导入真实场景图片/视频再标注  
- 训练工具若提示样本少，用「应用所选修复」跳回去增强  
- 建议每类至少有一定数量有效框，类别别极度偏斜  

### 没有 GPU 怎么办？

- 可以正常用，启动器会提示走 CPU  
- 训练时把批次大小调小（如 4），轮数可适当减少做试跑  
- 推理/对比也会更慢，视频尽量先抽关键帧或用短视频  

### 训练 loss 不下降？

- 检查学习率是否过大或过小（建议面板可一键改）  
- 确认 `data.yaml` 路径正确，train/val 里确实有图和标签  
- 标签类别 id 是否与 `names` 一致、框是否归一化到 [0,1]  
- 样本是否过少或标签质量差（先跑质检）  
- 可先用自动模式默认超参试一轮，看曲线再微调  

### 自动标注类别不对？

默认模型是 COCO 预训练。自定义业务类别需要先用自己的数据训练，再用得到的权重标注。

### 中文路径读图失败？

核心读写走了 Unicode 安全接口；若仍有问题，可把项目放到较短、无特殊符号的路径再试。

## 9. 快捷键 / 提示

本应用以按钮操作为主，无大量全局快捷键。实用提示：

| 提示 | 说明 |
|------|------|
| `--tool` | 跳过启动器，直接进某个工具 |
| `YOLOV8_WORKSPACE` | 固定项目目录，换机器也好复现 |
| 工作区「应用」 | 改路径后务必点应用，否则仍用旧目录 |
| 工具间联动 | 导出后「发送到模型训练工具」、训练侧「发送到图片/视频工具」 |
| 状态栏 | 各工具底部「状态」看进度与结果 |
| 环境面板 | 启动器底部看 Python / PyTorch / CUDA / GPU / 内存 |
| 设置 | 右上角「⚙ 设置」或「工具 → 设置」调节字体与缩放 |

建议流程：**导入 → 自动标注 → 质检/优化 → 数据增强 → 导出 → 训练 → 对比新旧权重**。
